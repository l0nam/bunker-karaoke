# 🎤 Karaoke Queue

**Karaoke Queue** — веб-приложение для организации караоке-вечеров на Discord-сервере **Bunker Online**.

Проект создан, чтобы сделать проведение караоке удобнее: ведущий может управлять участниками и порядком выступлений, а остальные пользователи — следить за происходящим в режиме реального времени.

🔗 **Discord-сервер:** https://discord.gg/bunkeronline

## ✨ Возможности

- **Управление очередью** — запись участников в основную и повторную очереди.
- **Управление выступлениями** — изменение порядка участников, перенос между очередями и удаление записей.
- **Поиск треков** — подсказки при вводе названия песни с информацией об исполнителе и обложкой.
- **Профили участников** — сохранение никнеймов и Discord ID для повторных посещений караоке.
- **Публичная страница** — просмотр текущего исполнителя, следующих участников и истории выступлений.
- **Управление для ведущего** — отдельная панель с инструментами организации вечера.
- **Адаптивный интерфейс** — удобное использование как на компьютере, так и на мобильных устройствах.
- **Обновления в реальном времени** — изменения очереди практически сразу отображаются у всех зрителей.

## 🎶 Для чего создан проект?

Karaoke Queue объединяет всё необходимое для проведения караоке-вечера в одном месте.

Вместо ручного ведения списка участников и постоянного объявления очереди ведущий получает удобный интерфейс, а посетители сервера могут самостоятельно следить за ходом мероприятия.

Главная цель проекта — сделать караоке более организованным, наглядным и комфортным для всех участников.
