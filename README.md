# Караоке-очередь

Живая очередь на караоке для Discord-сервера.

- `/` — публичная страница: кто поёт, кто дальше, поиск себя в очереди.
- `/host` — вход в панель ведущего по паролю.
- `/host/panel` — панель: добавление, «Следующий», перенос, сообщения для Discord.

## Запуск

1. Создай проект в Supabase и выполни `supabase/migrations/001_init.sql` в SQL Editor.
2. Скопируй `.env.local.example` в `.env.local` и заполни значения.
3. `npm install`
4. `npm run dev` и открой `http://localhost:3000`.

## Деплой на Vercel

Добавь все переменные из `.env.local.example` в настройки проекта.
`vercel.json` включает cron, который раз в три дня дёргает `/api/keepalive`,
чтобы бесплатный Supabase не уснул.

## Структура

- `app/` — страницы и API-маршруты
- `components/` — интерфейс (панель, публичная страница, тосты)
- `lib/` — авторизация, работа с очередью, сообщения Discord
- `hooks/` — `useQueue` с realtime-обновлениями
- `types/` — типы
- `supabase/migrations/` — схема базы
